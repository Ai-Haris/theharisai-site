Install help

Blocked on first open? Normal.

ClipShlip is not code-signed yet, so Windows and macOS warn about every new app like it. One step fixes it.

Windows

  1. Run the installer.
  2. If you see "Windows protected your PC", click More info, then Run anyway.
  3. If your antivirus blocks it, allow the file. It is a false positive for new unsigned apps.

macOS

  1. Unzip and drag ClipShlip to Applications.
  2. If it says the app is "damaged", that message is wrong. Paste this in Terminal once, then open it:
xattr -cr /Applications/ClipShlip.app
