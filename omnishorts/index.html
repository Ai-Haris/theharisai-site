How it works

Topic in. Finished MP4 out.

Claude shows you the plan (narration, captions, every shot) and waits for your yes before it builds anything.

ScriptClaude writes it the way a person talks, with checked facts and sources.
VoiceKokoro AI voice, local and free. Or ElevenLabs, or your own recording.
Word timingWhisper finds every word, so each cut and caption lands on it.
ShotsDrawn in code: canvas and three.js 3D, camera always moving.
SoundSound effects and music mixed under the voice, ducked and faded.
RenderHeadless Chrome captures every frame, ffmpeg makes the MP4.

Before the full render you get a storyboard (one frame per shot) to approve. Optional: when you ask, Claude uploads the finished short to your YouTube channel through Zapier, after confirming title, visibility and category.

Install

Three steps, about ten minutes.

1 Download and unzip

Put the omni-shorts folder in your Claude skills folder:

~/.claude/skills/omni-shorts/

2 Run setup and the self test

Inside that folder. Setup installs the free voice (about 340 MB) and Whisper (about 0.5 GB) and prints All set. The self test renders a short clip and prints SELFTEST PASSED. Or simply ask Claude to run both for you.

bash scripts/setup.sh
bash scripts/selftest.sh

3 Ask for your first short

Start a new Claude session, type /omni-shorts or just ask in plain words:

Make a Deep Dive 3D short: what happens if you crack your knuckles?

What you need

  • Claude Code, or Claude with a linked computer
  • Node.js 22+, ffmpeg, Google Chrome, Python 3.10+
  • About 1 GB free for the voice and Whisper models
  • No graphics card needed, no paid AI service
  • Windows: run the scripts in Git Bash (comes with Git for Windows; Claude Code already uses it)

FAQ

Questions

Is it really free?

Yes. The skill is free and every part of the pipeline runs on your computer: the Kokoro voice, Whisper word timing, drawing, sound and rendering. There are no API keys, no credits and no per-video fee. Only your Claude plan is used, as for any chat.

Can I use the videos on my monetized channel?

Yes. The code, stories, drawings and sound in the skill are original and free to use in your videos. Claude writes original scripts and checks facts against reliable sources. Use a format you like, never another creator's script or shots.

Does it work on Windows and Mac?

Both. On Windows, run the scripts in Git Bash. Any normal laptop works, no graphics card is needed.

Which style should I pick?

Body and science "what happens if": Deep Dive 3D or Inside Out. Mysteries and true crime: Night File 3D. Survival tips: Stick Story. History: Paper Atlas. Funny true stories: Tall Tale 3D. How things work or grow: Cutaway 3D. Build it yourself, problem by problem: Build Site 3D. Keep one style and one voice per channel.

Can it upload to YouTube for me?

Yes, when you ask. Claude uploads the finished short to your channel through Zapier and confirms the title, visibility and category first.

How is this different from OMNITUBE?

Omni Shorts makes short animated videos drawn entirely in code, inside Claude. OMNITUBE is a full desktop video studio for long YouTube videos and documentaries, with AI images, clips, voices and editing.
